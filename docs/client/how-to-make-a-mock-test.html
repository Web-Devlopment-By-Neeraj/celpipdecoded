How to make a mock test

You do not fill the spreadsheet by hand. Download the template, give it to an AI with your questions, then upload the file the AI returns.

What you need

  • The template, downloaded from the admin mock tests page. You can also use the copy sent with this guide.
  • Your questions and answers, in Word, PDF, or notes. Any layout is fine.
  • A free AI such as Claude. Attach both files and paste the prompt at the end of this guide.

The five steps

  1. 1
    On the admin mock tests page, download the template. Keep the header row. Keep every row whose use column says example. Those rows are a guide and are not saved.
  2. 2
    Attach the template and your question file to the AI. Paste the prompt from the last page. Ask for one CSV file and nothing else.
  3. 3
    On the same admin page, enter a title such as Mock Test 3 and a slug such as mock-test-3. Use mock-test-2 or later. mock-test-1 is the free built-in test and cannot be replaced.
  4. 4
    Upload the CSV. Read the checklist. If it names a problem, fix the file and upload it again. A file with an error is not saved. A warning does not block the draft.
  5. 5
    A clean file becomes a draft. Open it, then press Publish. Students on Test Sprint can then sit the test. It uses the same screens, instructions, and videos as Mock Test 1. Only the passage, the questions, the clip, and the picture change.
Do not add instructions, timers, or videos to the file. Those already live in the app and are the same on every test.

What to put in your question file

Listening and Reading need the passage, then each question: the question, the options, and the correct letter. An explanation is useful and optional.

Writing and Speaking are tasks. Write what the student must do. There is no correct answer and no options.

Name the part so the AI can pick the right type. The names are on the next page. A full test is six Listening parts, four Reading parts, two Writing tasks, and the Speaking tasks you want. A shorter file is allowed. A skill you leave out is shown as not in this test yet.

Audio and pictures

There is no button to upload an audio file or a photo. Put a public link in your question file, and the AI copies it into the spreadsheet.

  • A Listening clip goes in audio_url. A part with no clip still saves, and the checklist warns you.
  • A picture goes in image_url, with a short description in image_alt. Use this for a Reading diagram, a Writing picture, or a Speaking picture.
  • A diagram with no picture is rejected. A picture with no description is rejected.
  • The link must open in a browser. A private Drive file will not play for the student.
