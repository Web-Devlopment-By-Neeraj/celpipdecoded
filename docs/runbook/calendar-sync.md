# Calendar sync limits

Tool: hosted Cal.com, in the owner's name, connected to the owner's Google Workspace calendar and Zoom.

Always move or cancel a session from the admin calendar screen. A change made only in Google Calendar or Zoom does not email the student.

| Direction | What syncs | What does not notify the student |
| --- | --- | --- |
| Google to Cal.com | Busy times block bookable slots | Edits to an event title or time |
| Cal.com to Google | Create, update, and delete of bookings made in our app | |
| Zoom | A join link stored on the booking when we create or move it | A link edited inside Zoom |
| Admin screen | Reschedule and cancel, then email | |

The reconciliation job lists bookings whose start time no longer matches the calendar event.

Class blocks are eight sessions, Monday, Tuesday, Thursday, and Friday, 7:30 to 8:30 PM America/Toronto, including the week the clocks change. One Zoom link is stored on the batch.
